# Bannister case-study content checklist

Case studies must be based on real Bannister Communications work. Do not publish a location, customer type, result or photograph that Craig has not approved.

For each useful project, collect:

- Broad location only (for example, Maryborough or rural Fraser Coast)
- Property type (home, shop, shed, farm, worksite or office)
- Customer problem in one or two sentences
- Equipment or approach used
- Any installation constraint such as distance, power, obstructions or cable access
- Result achieved, without unsupported performance or crime-prevention claims
- Two to five original photographs with permission to publish
- Whether the customer can be named, anonymised or not quoted
- Optional short customer quote with explicit approval

Recommended first three case studies:

1. A Maryborough CCTV installation showing camera placement and tidy cabling
2. A rural wireless, solar-camera or Starlink project showing the physical challenge
3. A commercial alarm/CCTV project showing how the system was handed over

Each finished case study should link to the relevant service page and location page. It should include descriptive image alt text, a clear date and a call to request a comparable assessment.
